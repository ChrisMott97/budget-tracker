# Budget Tracker
A basic budget tracker being written without agentic code to learn React, Python and LLM integrations. 

## Planned Iterations
1. Process a bank transactions CSV to determine which columns are the useful data
2. Parse the messy and unstructured description fields to pull additional useful data
3. Parse transaction data to determine a category based on a preset list of categories
4. Deploy standalone, with the warning that transactions will be read by third party AI
5. Add accounts and persisted data. Requires deep research into security and data management to be safe. Consider hosted LLM.
